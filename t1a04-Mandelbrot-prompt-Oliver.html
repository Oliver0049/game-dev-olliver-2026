The Mandelbrot Set

Every pixel represents a complex number C. Starting with Z = 0, the renderer repeatedly applies this equation:

Zn+1 = Zn2 + C

If the sequence stays bounded, the point belongs to the Mandelbrot set and is colored black. If it escapes, the number of iterations determines its color.

Explore: Move the mouse to preview a zoom region. Use the mouse wheel to resize it, then click to zoom. The preview shows exactly which region will fill your screen.

Infinite complexity emerges from one simple equation.
